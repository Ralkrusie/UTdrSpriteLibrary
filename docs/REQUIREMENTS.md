# 功能约定

本文保留已确认的最终目标，不作为实现完成清单。构建与平台范围见 [BUILD.md](BUILD.md)，发布版本见 [GitHub Releases](https://github.com/Ralkrusie/UTdrSpriteLibrary/releases)。

## 定位与数据

- 名称为 **UTdrSpriteLibrary**，中文说明为「UT／DR 精灵素材管理与导出」。专注 UT／DR，不扩展通用游戏插件框架、绘画或复杂时间轴。
- 保留 Electron 跨平台路线，优先完成 Windows；素材、设置、导出、依赖与源码分开。
- 只读游戏包，提取前后校验源文件摘要。UT 读取 `data.win`；DR 按实际存在的 `chapterN_windows/data.win` 识别章节，不要求连续。
- 支持从游戏制作 ZIP 和直接导入 ZIP；验证后入库，可取消，不留下半成品。同内容重复导入提示已存在，同名不同内容允许共存。
- 多个游戏／补丁版本可独立命名、切换、删除；名称、版本、语言／补丁说明可编辑，未知版本可留空。导出素材包时选择路径和文件名，并写入有效元数据。
- 包内原始素材保持只读；个人设置与收藏按包隔离。同一 DR 包的相同变体合并章节，不同变体分别保留。

## 浏览与选择

- 支持名称搜索、章节／多帧／收藏／同名变体筛选、逐帧预览和输入页码跳转。
- 本页选择、全部筛选结果选择、清空与已选数量放在素材浏览区。勾选和收藏分别支持 Shift 区间操作，可跨页，包含两端，采用第二次点击的目标状态。
- 收藏保持原顺序，不前置；卡片用亮黄色边框，无专用底色。实心星标位于卡片右上角、详情名称后；卡片顶部最右 52px 用于收藏，其余区域勾选。
- 卡片宽度可调 180–360 px，默认 230 px，自动记忆；不改变导出倍率、当前页或勾选项。

## 导出与预设

- 支持 PNG 当前帧／全部帧、GIF、APNG、透明 MOV；MOV 保存一轮动画。原始 PNG 导出独立副本，字节不变，不用硬链接、不应用缩放。
- 默认 5×、3.75 FPS；速度提供 7.5 FPS 和自定义 0.1–120 FPS，缩放提供 1–10、15、20× 及自定义 0.25–20×。支持小数，显示实际整数像素尺寸；无效值不能导出。
- 批量与详情分别记忆格式、速度、缩放，关闭卡片或程序后恢复。批量导出针对已勾选条目。
- 预设由用户建立，不创建默认预设、不增加“选择预设”占位项。选中预设自动启用；启用时仅可切换预设，取消后才能改参数、名称、保存或删除。保留用户已有的 default 预设。
- 结果按素材包分组，手动导出放 `normal/`，拖拽放 `drag/`，素材包 ZIP 默认路径不变。媒体文件名不带哈希；动图带速度与缩放，PNG 带缩放与帧号，原始 PNG 标明 `original_1x`；同名用序号区分。
- 相同内容与参数重复导出先确认；已删除或修改的结果不算有效重复。拖拽复用完整相同结果，不覆盖旧导出；删除素材包不删除原始导入文件、个人设置或导出结果。
- 预览只用临时缓存，开始拖拽才正式保存，取消拖拽仍保留；清理缓存不删除已保存结果。导出保留来源与参数清单。

## 界面与运行

- DELTARUNE 菜单风格：黑底、白色直角分区框、框内标题、对齐的控件；不增加导出历史等无必要功能。
- 素材包说明与标题同行；“结果导出路径”的目录按钮位于输入框上方。详情播放／暂停放底部帧控制区；导出状态与打开目录按钮留出间距。
- 主按钮使用 `spr_dodgeheart` 第 0 帧原图（20×20）；英文标题使用 fnt_main 固定字形，默认 3×（357×48），420px 以下 2×；中文底部对齐，窄窗口换行。预设区域默认收起，显示使用中的预设名。
- 普通桌面用户无需安装 Python 或 FFmpeg；从游戏制作素材包使用随附专用提取器或外部 UMT，已有 ZIP 不依赖提取器。
- 后端静默运行，关窗时清理所属后端及子进程，不影响其他实例。优化体积时保留图形兼容组件及现有导出能力。
- 公开内容不带素材包、个人数据或开发环境；保留约定的红心与固定标题像素，不打包完整字体图集。许可说明见 [README](../README.md#许可)。
