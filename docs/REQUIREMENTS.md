# 已确认要求

## 定位
名称、窗口标题和界面标题统一为 UTdrSpriteLibrary；中文说明为「UT／DR 精灵素材管理与导出」，置于加粗英文主标题右侧，窄窗口自动换行。
先做 UT／DR 专用版，Windows 桌面优先。暂不扩展为任意 GameMaker 游戏或通用 PNG 编辑器，不加入绘画或复杂合成时间轴。

## 素材库
工具与素材包解耦。桌面和手机以 ZIP 素材包为目标，按需读取，不要求用户手动解压大量 PNG。
入口：通过 UMT 从游戏导入并制作素材包；直接导入现有素材包（不需要 UMT）。
支持多个游戏版本、汉化补丁版本共存，用户可命名、切换和删除。记录游戏、版本、语言/补丁说明、来源文件摘要及包格式版本；未知版本允许手填，不猜测。
DR 识别目录中实际存在的任意章节组合，不写死五章，不要求凑齐七章。没有额外的未来底层格式兼容框架需求。
UT／DR 条目身份独立；不同包同名资源不覆盖。DR 同包跨章相同资源可合并来源，不同资源保留变体。
ZIP 原始素材保持只读，收藏、别名、预设、保存路径等个人数据独立保存。
收藏具体素材包中的原始素材条目（全部帧），不是导出文件；支持仅看收藏，不同版本分别收藏。

## 浏览、导出、交互
保留名称搜索、章节/多帧/变体筛选、逐帧查看、速度和缩放设置。默认 5×、3.75 FPS；速度另有 7.5 FPS 和自填；缩放提供 1–10、15、20× 及自定义 0.25–20×（可填小数）；显示实际整数像素尺寸。
导出格式：PNG 当前帧、PNG 全部帧、GIF、APNG、MOV 无损透明。MOV 保存一轮动画，不承诺剪辑软件自动循环。
批量导出明确针对已勾选条目；预设由用户建立，不创建默认预设；有预设时列表只列出实际预设，不增加“选择预设”占位项。选预设自动启用；启用时只可切换预设，参数、名称、保存和删除均锁定，取消勾选后可编辑。已有用户命名的 default 预设保留。
导出按素材库分类，保留来源与参数信息。不覆盖旧导出，不随删除素材包删除导出结果。
“打开 PNG 文件夹”改为“导出原始 PNG 并打开目录”，输出独立副本，不用硬链接；不应用预览缩放。
桌面支持按当前格式拖出文件。预览只用临时缓存；开始拖拽才正式保存，取消拖拽仍保留；清理缓存不删除已导出文件。
界面尽量做减法、直角框，不增加导出历史等无必要功能。

## 桌面运行
仅显示素材库窗口，后端静默运行；关闭界面后所属后端及子进程完全退出，不影响其他实例。
普通用户不需安装 Python 或 FFmpeg。UMT 仅制作素材包时需要，现成素材包可独立使用。

## 待验证的建议默认值
以下方案最初提出时未逐项确认；当前构建与验证范围见 BUILD.md，公开分发准备情况见根目录 RELEASE_PREPARATION.md：
- ZIP 导入后复制到工具管理目录，同一内容重复导入提示已存在；同名不同内容允许并存。
- 随 Windows 完整包附带经验证的 UMT 命令行组件，并允许手动指定；须先验证运行与分发条件。
- 导入先校验后入库，避免半成品；个人数据在可明确对应同一素材时保留，不跨版本盲目关联。

## 2026-10-29 Windows 交互补充
- 支持编辑素材包名称、版本、语言／补丁说明；导出包包含修改后的信息。
- 导出素材包弹出保存路径和文件名选择；默认包输出仍在素材包分类目录，手动结果／拖拽结果分别进入 normal／drag。
- 主页输出位置称“结果导出路径”。收藏保持原有排序，不前置；卡片星标在右上角，详情星标在名称后，无框、已收藏黄色。
- 播放／暂停移到底部帧控制区；支持输入页码跳转。
- 从游戏制作时显示对应动作名称，清除切换流程后残留提示。
- UMT 可在验证提取行为的前提下精简，无需附带与本工具无关的脚本和开发文档。

## 2026-10-29 后续反馈
- 素材包信息输入框显示名称、版本、语言／补丁说明标签。
- 卡片顶部右侧收藏区域向右收窄，采用最右 52px；其余区域勾选，勾选框适当增大。
- 勾选和收藏分别支持 Shift 区间操作，按当前筛选结果顺序，可跨页；包含两端，采用第二次点击的目标状态。
- 普通导出目录称 normal，拖拽称 drag，素材包 ZIP 默认位置保持不变。
- 素材文件名不带哈希；同名时用序号区分，避免覆盖。
- 再次导出相同素材和参数时先确认；已删除或修改的结果不算有效重复。拖拽复用完整相同结果，避免反复生成副本。
- 导出完成状态与打开文件夹按钮留出间距。
- UMT 尽量只保留提取需要的部分，验证 UT／DR 完整性后再采用。

## 2026-10-30 显示与体积反馈
- 结果导出路径的“选择目录”“打开目录”移到上方，路径输入框占满下方宽度。
- 动图与 MOV 文件名带速度和缩放，例如 spr_name_Ch2_3.75fps_5x.gif；PNG 没有播放速度，标缩放和帧号，原始 PNG 明确 original_1x。
- 分析软件本体体积；发现的重复运行依赖可在验证功能后修正。更换外壳或定制编码器属于待评估方案，未要求本轮实施。

## 2026-10-30 菜单风格（含后续反馈）
- 采用 DELTARUNE 菜单风格方案：黑底、白色直角分区框；分区标题放到框内，保持边线完整连续，去掉错位边线和角饰。
- 黄色五角星表示收藏，主要操作用白框和红心点缀；素材卡片边线较轻，勾选后白框突出。
- 素材包与结果导出路径在宽窗口中并排，路径按钮位于输入框上方；搜索、筛选和页码集中在素材浏览区。
- 预设编辑默认收起，使用中的预设名称仍在折叠标题中可见；详情保留名称旁的收藏和底部播放控制。
- 首版沿用系统清晰字体与等宽标题／资源名，具体像素字体后续细化。
- 按钮高度、间距和分组对齐统一；参数标签位于输入框上方，详情导出按钮集中在参数旁，拖拽状态与尺寸信息归为一行，窄窗口换行。
- 红心采用 DR 的 spr_dodgeheart 第 0 帧原图（20×20），不用手绘 CSS 代替；原图作为独立本地 UI 依赖保存。

## 2026-10-30 预设与浏览调整
- 本页／全部筛选结果／清空选择及已选数量归入素材浏览区。
- 收藏卡片增加稍亮的底色，保留黄色星标、勾选白框与原有顺序。
- 批量导出、详情预览与拖拽统一支持 0.25–20× 的自定义缩放；越界或空值不能导出，预设保留小数倍率。
- 素材浏览提供卡片大小滑杆，控制卡片目标宽度与预览区高度、自动调整每行数量；范围 180–360 px，默认 230 px，设置持久化。此项不改变导出倍率、当前页或已勾选内容。

## 2026-10-30 自动记忆反馈

- 收藏卡片改用亮黄色边框，取消专用底色。
- 素材包说明移至标题同行，压缩框高度。

## 游戏字体标题试用
- 英文主标题采用游戏 fnt_main 原始字形，默认以 3× 整数倍显示（357×48），420px 以下窗口采用 2×；中文说明与英文标题底部对齐；中文说明、分区和正文维持现有字体。

## 体积优化与跨平台
- 跨平台能力优先，保留 Electron，不迁移为 Windows 专用外壳。优先裁剪不使用的资源，保留图形兼容组件和现有导出能力。Windows 先验证，其他系统不视为已完成适配。
